关于「今日热搜」

这是什么

把微博、知乎、百度三个平台的热榜聚合在一页里浏览的小工具，纯前端实现（HTML / CSS / JavaScript），无后端、无数据库。

数据来源

榜单数据来自开源接口 60s API，每次打开或点「刷新」时实时拉取；拉取失败时会自动重试，并回退显示上次成功的数据（页面会标注「可能过期」）。

功能

  • 点任意条目展开详情，可查看原文、收藏、写备注
  • 收藏和备注保存在浏览器本地（localStorage），只存在你这台设备上
  • 顶部导航可在「热榜 / 收藏 / 关于」三个视图间切换，支持浏览器前进/后退

演示模式

网址后面加 ?mock=1 用本地假数据演示（不联网）；再加 &empty=1 可以演示「暂无数据」的空状态。
