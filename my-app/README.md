# 今日热搜 · my-app（MVP 第一版）

> Day 7 产出 · 2026-09-30 · 技术路线 A：纯 HTML + CSS + JavaScript（无框架、无构建、无后端）

## 这是什么

「今日热搜」MVP：一个网页，打开 3 秒内看到微博、知乎、百度三栏热搜榜单；点条目看详情、跳原文；可收藏并写备注（存在浏览器本地）。

- 需求依据：`../PRD.md`（F1 榜单 / F2 详情 / F3 收藏备注）
- 技术依据：`../TECH_DESIGN.md`（技术路线与数据流）

| 文件 | 作用 |

## 关键词筛选（Day 12 新增，按 Skill 实现）

热榜视图顶部有筛选框：输入关键词，三个榜单同时实时过滤（纯前端过滤内存数据，不发请求）。

- **有结果**：只显示标题含关键词的条目，右上角实时计数（如「2/16 条」）
- **无结果**：该栏显示「没有匹配「关键词」的条目」+「清空筛选」按钮（空态，不是报错）
- **清空恢复**：删掉文字或点「清空筛选」，三栏恢复全量
- 筛选词在空态文案里回显时会做 HTML 转义（防注入）；点「刷新」重新拉数据时筛选自动清空

## 怎么启动（运行命令存档）

在本文件夹（`my-app/`）里任选一条命令启动本地静态服务：

```bash
# 方式一：Python（本机已装 3.13）
python -m http.server 8000

# 方式二：Node（本机已装 22）
npx serve -l 8000 .
```

然后浏览器打开：**http://localhost:8000**

> 注意：不能直接双击 index.html 用 file:// 协议打开——部分浏览器会限制本地文件发网络请求，用 localhost 服务打开才和真实使用一致。

## 三个视图（Day 13 新增，hash 路由）

顶部导航可在三个视图间切换。**地址里的 `#` 就是当前视图**，可以直接分享或收藏某一条地址：

| 地址 | 视图 |
|---|---|
| `index.html#/hot` | 热榜（默认，打开时若没带 hash 会自动补上） |
| `index.html#/fav` | 我的收藏 |
| `index.html#/about` | 关于（数据来源与用法说明） |

- 用的是浏览器原生 hash：只有 `hashchange` + `location.hash` 两个 API，没有引入任何路由库
- **支持浏览器前进 / 后退键**（每条 hash 都会进入历史记录）
- 认不出来的 hash（比如 `#/xyz`）会兜底显示热榜
- 切换视图只做显示/隐藏，不重新加载页面，也不会重新请求数据
- 「刷新」按钮只在热榜视图出现（收藏和关于不联网拉数据）


## 演示模式（mock 假数据，Day 8 新增）

不想受第三方接口影响时（接口抽风、断网、给别人演示、交作业截图），在地址后加参数：

| 地址 | 效果 |
|---|---|
| `http://localhost:8000/?mock=1` | 三栏全部用 `mock.js` 里的本地假数据渲染，**不发任何网络请求** |
| `http://localhost:8000/?mock=1&empty=1` | 同上，另外把知乎栏变成「暂无数据」空状态（演示四种页面状态） |
| `http://localhost:8000/` | 正常模式：请求真实接口 |

进入演示模式时，副标题会显示「【演示模式：本地假数据】」、每栏右上角显示「演示数据」，避免和真实数据混淆。


## 数据来源

使用开源项目 **60s API**（https://60s-api.viki.moe ，作者 vikiboss/60s）的公开接口：

| 平台 | 端点 |
|---|---|
| 微博热搜 | `GET /v2/weibo` |
| 知乎热榜 | `GET /v2/zhihu` |
| 百度热搜 | `GET /v2/baidu/hot` |

- 接口带 `Access-Control-Allow-Origin: *`（跨域允许），前端可直接调用，无需代理
- 2026-09-30 实测三个端点全部可用；原候选 DailyHotApi（dailyhot-api.imsyy.top）域名已失效，已按 TECH_DESIGN.md 备选方案切换（详见 TECH_DESIGN.md 第二节说明）

## 已知限制

- 收藏数据存浏览器 localStorage：换浏览器 / 清缓存会丢收藏（PRD 附注已知且可接受）
- 数据来自第三方公开接口，接口挂了页面会按顺序降级：自动重试 3 次 → 显示上次数据（标注可能过期）→ 才显示失败提示 + 重试按钮
- 第三方接口偶尔会「正常返回但 0 条」，此时显示「暂无数据」而不是失败（Day 8 区分了这两种状态）
- 仅在 Chrome / Edge 最新版验证
